📌 शाळेच्या पद्धतीने UI शिका

लोक प्रत्यक्षात काय पाहतात, ते शाळेच्या सूचना फलकाच्या रूपात शिकवलेले: रचना, दिसणे, आणि कोणी स्पर्श केल्यावर काय घडते. प्रत्येक धडा म्हणजे क्रमांकित आकृती असलेली शाळेची गोष्ट — आणि फलक रेपोच्या आतच आहे: तीन साध्या फाइल्समधले खरे web ॲप (HTML, CSS, JavaScript — framework नाही, build पायरी नाही) आणि बोलण्यासाठी एक छोटे काउंटर, जे प्रत्येक धडा वाचतो, मोडतो आणि सुधारतो.

🧱 HTML🎨 CSS⚡ JavaScript🧠 state♿ a11y🎽 tokens🚀 performance🧪 testing

🧱 भाग 1 — फलक (1–6)

  • लोक जे पाहतात तेच उत्पादन 📌
  • अर्थ असलेली रचना, वाकणारा layout 🧱🎨
  • फलक जिवंत होतो: events, fetch ⚡
  • सत्याचा एकच स्रोत; प्रत्येकजण वाचू शकतो 🧠♿

🚚 भाग 2 — पाठवणे (7–12)

  • frameworks, आणि साधे JavaScript कधी पुरते 🧰
  • गणवेश: tokens आणि dark mode 🎽
  • वेगवान, तपासलेला, काउंटरशी सुरक्षित संवाद 🚀🧪📨
  • भिंतीवर लावलेला: build, deploy, निरीक्षण 🚚
